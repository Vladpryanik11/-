# Дизайн-система: портфолио маркетолога

Собрано по итогам разбора двух референсов и брифа (`prompt.md`).

## Что взято из референсов

**№1 New Way Of Living (glassmorphism/real estate).**
Плавающая пилюля-навигация из полупрозрачных стеклянных капсул поверх атмосферной
фотографии/градиента; очень крупный радиус скругления (24–40px); мягкие тени, разлитые
широко и слабо (не резкие); иконки в круглых/квадратных «стеклянных» плашках; текст
поверх фото читается за счёт лёгкого затемнения и самого стекла, а не рамок; много
воздуха вокруг блоков, элементы «парят» друг над другом внахлёст.

**№2 Ethan Brady (photographer portfolio).**
Огромное фото специалиста на первом экране, есть с кем ассоциировать бренд с первого
взгляда; контрастная смена ритма — светлый блок → чёрный блок → светлый блок; портфолио
организовано как список категорий, разворачивающихся в сетку превью; крупная плашка-CTA
(pill-button) поверх фото.

## Синтез: как это работает вместе

Свето-атмосферный сайт (не тёмный, как у Ethan Brady) с приёмом glassmorphism как у New
Way Of Living, но ритм секций чередуется по контрасту, как у Ethan Brady: атмосферная
секция → светлая плоская → тёмная (портфолио) → атмосферная (контакты). Каждая секция
переключает fON/BG-режим, поэтому визуально сайт не «плоский лонгрид», а последовательность
разных по настроению экранов — что прямо требует бриф.

## Типографика

- **Заголовки/акценты:** `Unbounded` (Google Fonts, есть кириллица) — геометричный,
  скруглённый, с «мягкими» формами букв — перекликается с скруглёнными карточками.
  Начертания 500/600/700. Крупные заголовки набраны с отрицательным трекингом и
  плотным line-height (0.98–1.05) для плакатности, как в обоих референсах.
- **Основной текст/интерфейс:** `Inter` (400/500/600) — нейтральный, отличная кириллица,
  хорошо работает мелким кеглем в стеклянных плашках.
- Масштаб — модульный, через `clamp()`: H1 ≈ clamp(2.4rem, 5vw+1rem, 5rem), H2 ≈
  clamp(1.8rem, 3vw+1rem, 3rem), body ≈ 1rem–1.125rem. Никаких выключенных по ширине
  длинных абзацев — короткие строки, много переносов, «мало текста» по брифу.

## Сетка и пространство

- Контейнер `max-width: 1240px`, паддинги по краям `clamp(20px, 5vw, 64px)`.
- Вертикальный ритм секций: `padding-block: clamp(72px, 11vw, 160px)` — секции дышат,
  между смысловыми блоками внутри секции шаг 8px-кратный (16/24/32/48/64/96).
  Сервисы — сетка 5 карточек (auto-fit, minmax 220px), портфолио — 2–3 колонки по
  категориям, адаптив в 1 колонку на мобиле.

## Палитра

Светлая, атмосферная, без резких контрастов кроме одной тёмной секции-паузы.

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#F6F5F2` | базовый фон страницы (тёплый, не стерильно-белый) |
| `--sky-1` | `#CFE0FF` | голубой в атмосферном градиенте |
| `--sky-2` | `#E3D6FF` | лавандовый в градиенте |
| `--sky-3` | `#FFE1CF` | персиковый в градиенте |
| `--ink` | `#1B1B22` | основной текст |
| `--ink-soft` | `#5B5C68` | вторичный текст |
| `--glass-bg` | `rgba(255,255,255,.55)` | заливка стеклянных карточек на светлом фоне |
| `--glass-bg-dark` | `rgba(255,255,255,.08)` | заливка стеклянных карточек на тёмной секции |
| `--glass-border` | `rgba(255,255,255,.6)` | окантовка стекла |
| `--accent` | `#4338EC` | индиго — CTA, ссылки, акцентные обводки |
| `--accent-soft` | `#EDEBFF` | подложка под иконки/теги на светлом |
| `--coral` | `#FF7A59` | тёплый акцент для тегов категорий портфолио |
| `--dark-bg` | `#141319` | фон тёмной секции портфолио |

Один яркий акцент (индиго) + один тёплый акцент (коралл для категорийных тегов) —
остальное нейтрально, чтобы не спорить с фото специалиста.

## Приём «жидкое стекло» — как применяется по всему сайту

Everywhere: `background: var(--glass-bg); backdrop-filter: blur(20px) saturate(160%);
border: 1px solid var(--glass-border); border-radius: 28px; box-shadow: 0 20px 60px
rgba(31,35,74,.12)`. Карточки всегда лежат **поверх** чего-то атмосферного — фото,
градиентной сетки или тёмного фона, никогда поверх ровной заливки без подложки, иначе
эффект теряет смысл. Стекло используется на трёх уровнях:

1. **Навигация** — плавающая капсула, стекло + сильный blur, крепится к верху при скролле.
2. **Плашки на фото героя** — маленькие «орбитальные» карточки-теги с иконками услуг,
   внахлёст на фото, с лёгким покачиванием (subtle float animation).
3. **Карточки контента** — услуги, шаги подхода, контактная карточка — тот же язык, но
   крупнее и с реальным контентом.

## Ритм блоков (структура страницы)

1. **Header** — плавающая стеклянная пилюля-навигация (как №1).
2. **Hero** — атмосферный градиентный фон, крупное фото специалиста справа, заголовок и
   плашки-теги услуг слева/поверх фото (как №2 по композиции, как №1 по стилю плашек).
3. **Услуги** — светлая плоская секция, 5 стеклянных карточек-иконок в сетке.
4. **Подход** — светлая секция, 3 шага в виде горизонтальных стеклянных полос (контраст
   ритма: из сетки в список).
5. **Портфолио по категориям** — тёмная секция (контраст к светлым, как у Ethan Brady),
   табы категорий + сетка карточек-кейсов (только визуал и название, без цифр/цен).
6. **Контакты** — снова атмосферный градиент (рифма с hero, «закольцовка»), одна крупная
   стеклянная карточка с CTA.
7. **Footer** — минимальный, тёмный, тонкая строка.

## Чего нет (по брифу)

Никаких цен, отзывов, точных цифр результатов (%, ₽, «+X клиентов» и т.п.). Кейсы в
портфолио — только название/категория/визуал-заглушка, помечены как примеры оформления,
а не реальные результаты.
