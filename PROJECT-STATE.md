# Состояние проекта и ключевые решения

Этот файл — конспект для продолжения работы в новой сессии Claude Code (в т.ч. на другом устройстве), чтобы не терять контекст долгой переписки. Исходное ТЗ — см. [ORIGINAL-BRIEF.md](ORIGINAL-BRIEF.md).

## Что это

Многостраничный статический сайт-портфолио маркетолога для российского рынка. Файлы: `index.html` (Главная), `services.html` (Услуги), `portfolio.html` (Портфолио), `blog.html` (Блог), `contact.html` (Контакты), общие `css/styles.css` и `js/main.js`. Дизайн-система описана в `design-system.md`.

- Matt Pocock skills (`.agents/skills/`, `.claude/skills/`) — `implement`, `tdd`, `codebase-design`, `domain-modeling`, `diagnosing-bugs`, `writing-for-agents`, `handoff` и др.
- Nick Vels Autopilot (`.agents/skills/autopilot`) — для задач в духе «собери под ключ, не задавай лишних вопросов».

## История hero-секции Главной (несколько итераций редизайна)

1. Исходный hero: фото в прямоугольной рамке + 3 стеклянных бейджа.
2. Визуальный полишинг: типографика, layered glassmorphism-тени, размытые цветные пятна фона, редизайн иконок.
3. Замена фото на прозрачный вырез (`specialist-2.png`, в полный рост, с чашкой кофе), рамка убрана — силуэт лежит прямо на градиенте, добавлены дизайнерские подписи-каллауты голубым (потом убраны по итогам критики).
4. Критика hero (через `design:design-critique` + агент) выявила баги: мобильный порядок фото/текста, обрезка подписи на 1024px, визуальный перегруз. Баги пофикшены, слой подписей удалён.
5. Полный редизайн под референс "ВЛАДИСЛАВ" — ледяная бело-голубая палитра (только в hero), 5 пронумерованных стеклянных карточек услуг (изображения сгенерированы через Figma MCP — 2 через шейдеры, 3 вручную как SVG той же техникой, лежат в `images/cards/`), рукописный акцент-текст (шрифт Marck Script), придуманные локальные бренды.
6. Финальная замена фото на `specialist-3.png` (портрет по плечи/профиль) + эффект «текст позади фото» (референс — сайт "MILAR": часть заголовка «МАРКЕТОЛОГ» визуально уходит за голову, z-index-приём), карточки/акцент переставлены вокруг новых пропорций фото. Старое фото `specialist-2.png` оставлено на диске неиспользуемым.

## Технические заметки

- Локальный превью-сервер: `npx --yes serve -l 5000 "путь до проекта"` (Node.js 22 LTS установлен через winget; `node`/`npx` не в PATH по умолчанию в Git Bash — добавлять `/c/Program Files/nodejs` вручную).
- В браузерном инструменте предпросмотра этой среды (Claude_Browser) есть известный баг: быстрый скролл или переход по якорным ссылкам иногда даёт «залипший»/неактуальный скриншот. Это баг инструмента, не сайта — перепроверять через `getComputedStyle`/`getBoundingClientRect` или свежую вкладку, а не считать сайт сломанным по одному скриншоту.
- ⚠️ На компьютере пользователя диск C: был заполнен под 100% (на 2026-09-11 — 248 МБ свободно из 112 ГБ). Стоит напомнить почистить диск, если снова будут проблемы с записью файлов.
